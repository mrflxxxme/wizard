Профиль pilot: runtime и worker раскатываются `Recreate` (`<svc>.strategy` в чарте) — при RollingUpdate сторож старого процесса пересоздавал поды, которые новый уже убрал, и они навсегда занимали квоту; цена — несколько секунд без функций и сборок на выкат. Открыто: метка экземпляра для подов песочницы (нужна для нескольких реплик runtime и уборки по метке).

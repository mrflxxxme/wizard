# Запись на услуги
> Услуги и свободное время, запись без входа, подтверждение и напоминание посетителю по почте, отмена по ссылке, расписание у персонала.

Когда: segment=booking или в карточке есть запись на время.

Данные
- service: название, длительность в минутах, цена (только если она есть в карточке).
- booking: ссылка на услугу, starts_at (дата и время), статус «новая → подтверждена → отменена / прошла», имя, телефон и почта посетителя (pii=basic), retention по карточке.
- specialist — если в карточке несколько мастеров; запись ссылается на мастера.
- Одно время — одна запись: индекс по (specialist, starts_at) или по starts_at и проверка в функции записи с ctx.error("SLOT_TAKEN"). Для групп — лимит мест в функции с ctx.error("NO_SEATS").

Права
- Публичная роль: read услуг, create записи через функцию; чужие записи не читает.
- Персонал: read и update записей; владелец — всё.

Автоматизации
- on_create записи → notify email посетителю (подтверждение со ссылкой отмены) и владельцу. Точный формат подключений и шагов notify — get_capability notify.
- Напоминание: trigger schedule с relative {field: starts_at, offsetMinutes: -1440} → notify email посетителю, только для статуса «подтверждена».
- Отмена по ссылке из письма: mutation по неугадываемому токену записи переводит её в «отменена» и освобождает время.
- SMS нет: посетителю — только почта, владельцу — почта и Telegram.

Экраны
- Публичная страница: услуга → свободное время → имя и контакт с согласием (ConsentCheckbox) → экран «Вы записаны».
- Персонал: расписание на день (DataTable с фильтром по дате) или доска StatusBoard по статусам.

Тексты: названия услуг, цены и длительность — только из карточки; если их нет, заглушки «Пример: …».

Критерии для QA: аноним записывается на свободное время; вторая запись на то же время — ошибка; за 24 часа до начала уходит письмо-напоминание (advanceTime + outbox email).

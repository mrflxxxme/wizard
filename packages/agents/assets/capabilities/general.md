# Любая задача вне рецептов
> Общий порядок для брифа без подходящего рецепта: состав системы — из карточки, честный ответ о том, чего нет.

Когда: segment=other или horizontal, либо задача смешивает несколько рецептов (тогда возьми из каждого подходящие части).

Порядок
- Состав системы берётся только из карточки: роли, данные, права, автоматизации, экраны. Не добавляй разделы, которых в ней нет.
- Данные → права (минимальные, как в card.roles[].can) → автоматизации → объявления функций и экранов → критерии приёмки 1:1 → compliance.
- Публичные формы с ПДн — с согласием; ПДн в Telegram не отправляем.
- Всё, что в карточке помечено «Пока не войдёт» (outOfScope), не собираешь. Встретил такое по ходу сборки — report_capability_gap и замена из карточки.

Экраны
- Компоненты ui-kit вместо своей вёрстки; для публичной страницы подойдут блоки лендинга из рецепта site.
- У каждого списка и формы есть состояния загрузки, пустое и ошибки.

Тексты — по правилам «Тексты для людей»; чего нет в карточке, не придумывай.

## Что сильнее всего меняет план

1. **Конкуренция.** Яндекс VibeCraft публичен с июня 2026, а Битрикс24 Вайбкод открыт с апреля. Тезис «аналога нет» снят. Отличие строим на нише, надёжности в проде и контуре amoCRM.
2. **Вертикаль.** Запись на услуги (салоны, студии) закрыта DIKIDI и YCLIENTS. Предложено сместиться в заказные услуги, начиная с ремонта и отделки.
3. **Срок.** v0.1 в исходном объёме — это 145–180 человеко-дней при ~65 доступных, плюс 25–35 дней юридической работы. Объём сокращён, бета перенесена на 6-й месяц.
4. **Модели.** В РФ, во внутреннем контуре, доступны GLM-5.1, Kimi-K2.6, DeepSeek-V4-Pro (уровень Opus 4.6). «Внешние» модели Cloud.ru отправляют данные за рубеж, для ПДн они запрещены.
5. **Изоляция кода.** workerd — не песочница, его нужно запускать внутри gVisor или microVM.
6. **Право.** Новый вопрос по 149-ФЗ: не становится ли Wizard провайдером хостинга. Чат-виджет из v0.1 убран из-за риска статуса ОРИ.
7. **Экономика.** Сборка обходится примерно в 46–96 ₽ (оценка). Курс: 1 кредит ≈ 5 ₽. Главная неизвестная — реальный токен-профиль сборки, его нужно замерить на неделе 0.

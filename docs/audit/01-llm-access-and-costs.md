- **Внешние модели.** Об их запросах условия говорят прямо: они «передаются по сети Интернет на серверы соответствующих провайдеров». Риски по ПДн несёт заказчик, SLA на внешние модели не распространяется ([условия 1.EVO.11.2](https://cloud.ru/documents/contracts/terms-of-service/evolution/foundation-models/description-foundation-models)). Поэтому GLM-5.2 и V4-Flash **нельзя** использовать для ПДн клиентов Wizard.
- **API.** OpenAI-совместимый, `https://foundation-models.api.cloud.ru/v1/` ([API](https://cloud.ru/docs/foundation-models/ug/topics/api-ref)). Function calling, structured output и MCP для GLM-5.1, K2.6 и V4 заявлены в [анонсе](https://cloud.ru/blog/glm-5-1-kimi-k2-6-i-deepseek-v4). Насколько строго соблюдается `json_schema`, не проверено **[?]**.
- **Лимиты.** 20 запросов в секунду на сервисный ключ, RPM ключа можно настроить. TPM не опубликован **[?]**. Для большей производительности предлагают выделенный инстанс в ML Inference ([продукт](https://cloud.ru/products/evolution-foundation-models)).
- **Кэширование промптов.** Скидки на кэш есть только у партнёрских моделей Anthropic. У внутренних моделей скидку не нашёл **[?]**, а для агентных циклов это важно.
- **SLA.** Для внутренних моделей действует общий SLA Evolution: 99.95% и компенсация 10/20/50% ([2.EVO.0](https://cloud.ru/documents/contracts/terms-of-service/evolution/service-level-agreement.html)). Модель, выведенную из каталога, недоступностью не считают: каталог может меняться без компенсации.
- **152-ФЗ.** Платформа Evolution аттестована по УЗ-1 ([сертификаты](https://cloud.ru/docs/evolution/overview/topics/security__compliance)). FM в перечне отдельно не упомянут **[?]**. По условиям, для ПДн допустимы только локально развёрнутые (внутренние) модели. Внутренние модели запросы не логируют.

- OpenRouter 11.05.2026 отключил платежи для аккаунтов из РФ. Это официальное письмо, пересказанное на [Хабре](https://habr.com/ru/news/1034012/). По словам Cloud.ru, в июне OpenRouter полностью прекратил обслуживать российских клиентов ([Инк.](https://incrussia.ru/news/cloud-ru-otkryl-rossijskomu-biznesu-dostup-k-zarubezhnym-ii-modelyam/)). - **Новое.** Cloud.ru продаёт «партнёрские» Claude (до Opus 4.8), GPT (до 5.5) и Gemini (до 3.1 Pro) за рубли. Например, Opus 4.8 стоит 854 / 4 270 ₽, Sonnet 4.6 — 589 / 2 946 ₽. ## A5. Юнит-экономика

**Допущения.** Агентная нагрузка в основном состоит из входа, примерно 80% токенов. Профили:
- низкий: 190k токенов;
- средний: 320k (интервью 15k, план 30k, строители 200k, QA 75k);
- высокий: 450k;
- правка: около 75k.

Кэш-скидок нет.

| Микс | Сборка: низ / сред / выс, ₽ | Правка, ₽ |
|---|---|---|
| A. Kimi K2.6 (оркестр) + V4-Pro (строители) + GLM-5.1 (QA), Cloud.ru | 57 / **96** / 133 | 22 |
| B. Kimi K2.6 + Qwen3-Coder-Next + gpt-oss-120b, Cloud.ru | 29 / **46** / 62 | 11 |
| C. Qwen3-235B + DeepSeek-V4-Flash, Yandex | 79 / **128** / 177 | 29 |
| Ориентир: всё на Sonnet 4.6 (внешняя модель Cloud.ru) | 204 / 339 / 473 | 78 |

**Стресс-тест.** Если контекст пересылается на каждом шаге и есть ретраи, реальный прогон легко выходит на 1–1.5M токенов. Тогда сборка стоит около 300–500 ₽ на миксе A и около 180 ₽ на миксе B **[?: подтвердить первым прогоном]**. Эскалация 10% шагов на Opus 4.8 добавляет примерно 40–60 ₽.

**Бюджет на LLM при валовой марже ≥70%.** Себестоимость должна быть не больше 30% выручки. Из неё вычитаются хостинг, около 150 ₽ за систему в месяц **[?]**, и эквайринг, около 3%:

| Тариф | Бюджет на LLM | Микс A (сред.) | Микс B |
|---|---|---|---|
| Старт 2 000 ₽ (УСН без НДС; 2 системы) | ~240 ₽ | 1 сборка + 6 правок | 2 сборки + 13 правок |
| Старт при НДС 22% | ~140 ₽ | 1 сборка + 2 правки | 1 сборка + 8 правок |
| Бизнес 7 000 ₽ (5 систем) | ~1 140 ₽ | 4 сборки + 35 правок (или 12 сборок) | ~25 сборок |

**Предложение по кредитам.** 1 кредит — это около 5 ₽ себестоимости LLM.
- Сборка списывает около 20 кредитов по факту, но не больше лимита из карточки. Правка — 3–6 кредитов.
- «Старт»: 50 кредитов в месяц.
- «Бизнес»: 230 кредитов в месяц.
- Free: 25 кредитов один раз (одна draft-сборка обходится примерно в 125 ₽ CAC).
- Докупка по ~17 ₽ за кредит, например 60 кредитов за 990 ₽, держит маржу на уровне 70%.

## A6. GPU в РФ

H100 — от 251.64 ₽/ч, H200 — от 312.36 ₽/ч за карту с НДС у Intelion ([Intelion](https://intelion.cloud/h100-h200/)). По сводке [GPU Индекс](https://gpuindex.ru/gpus/nvidia-h200), H200 стоит от 375 ₽/ч у Intelion, 423 ₽/ч у Immers, 656 ₽/ч у Selectel (помесячно) и 1 086 ₽/ч у VK. Готовые узлы 8×H200 в листингах не видны: максимум 4 карты в конфигурации, 8 карт — под заказ **[?]**. Узел 8×H200 обходится в 2.5–5.2 тыс. ₽/ч, то есть 1.8–3.8 млн ₽/мес. Для сравнения, на API миксе A за эти деньги можно сделать около 20–40 тыс. средних сборок в месяц. Своё железо имеет смысл только при масштабе, либо чтобы закрепить модель (например, GLM-5.3 или Kimi K3), которой нет среди внутренних моделей Cloud.ru.

# L3 — аудит спек: безопасность, ПДн (152-ФЗ), граница данных T0/T1, злоупотребления, право и лицензии

Дата: 2026-09-30. Объект: `specs/**`, `AGENTS.md`. Контекст: `docs/audit/03-legal-and-licenses.md`, `docs/research/data-boundary-frontier.md`, `docs/week0/zai-contract.md`, `specs/CHANGELOG.md`.
Рамки: только безопасность, приватность, право. Согласованность, исполнимость и верность концепции проверяют другие аудиторы.

**Итог:** 43 находки: critical 1, high 11, medium 25, low 6.
Тип: **SPEC** — исправляется правкой спеки. **E-LEGAL** — нужна позиция юриста (спека фиксирует безопасный вариант по умолчанию до ответа). **E-DECISION** — меняет зафиксированное решение.
Веха — когда правка MUST попасть в спеку: к началу задач этой вехи.

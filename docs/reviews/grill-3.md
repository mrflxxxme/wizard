# Грилл-3: партнёры, бренд, кастомизация, мобильность, совместная работа, runtime-ИИ (30.09.2026)

Основа: [концепция v3](../concept.md), раздел 8.

| # | Вопрос | Решение основателя |
|---|---|---|
| 1 | Дизайн-партнёры | Есть контакты: **6–8 партнёров на неделе 0** — 3–4 заказчика ивентов из прошлых заказов и 3–4 производителя или продавца товаров на заказ. От каждого 3 реальных брифа без ПДн, созвоны раз в 2 недели, одно реальное событие или продажа в бете. Взамен — год «Бизнеса» |
| 2 | Название | «Wizard» остаётся кодовым именем. Финальное имя выбираем к **12-й неделе**; до этого шорт-лист проверяется по ФИПС и доменам (направления: Лекало, Затея, Верфь, Каркас) |
| 3 | Внешний вид систем | Три уровня в MVP: панель **«Стиль»** (токены: цвета, шрифт, скругления, плотность, логотип, светлая и тёмная тема; мгновенно, без кредитов), **«укажи и измени»** (клик по элементу в превью + инструкция, +4–5 дней), **чат** для остального. Drag-and-drop редактора нет |
| 4 | Мобильность | Все системы — адаптивные **PWA**. **Офлайн-сканер QR**: билеты скачиваются заранее, синхронизация при появлении сети (+3–4 дня). Пуши через Telegram. Нативные приложения — после публичного запуска и только по спросу |
| 5 | Совместная работа | **Команда в организации**: владелец, редактор, наблюдатель. Публикует в prod только владелец. В системе одна сборка за раз: блокировка, очередь, статус «кто меняет». Синхронное редактирование — после запуска. Около +3 дней; основа для тарифа «Агентство» |
| 6 | ИИ внутри систем | Два типизированных ИИ-действия для воркфлоу и кнопок: **«Извлечь или классифицировать»** (текст → поля по схеме) и **«Сгенерировать текст»**. Только T0 (Qwen3-Coder-Next или gpt-oss-120b в Cloud.ru), оплата кредитами по факту с месячным лимитом на систему, около +4–5 дней. Чат-боты и RAG — после запуска |

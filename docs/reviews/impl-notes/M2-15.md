- 2026-10-01 · M2-15 · `WIZARD_PAYMENTS=on|off` (off, false и 0 считаются выключением; по умолчанию on). Выключено: startCardBinding, changeSubscription (PUT), cancelSubscription и createTopup отвечают 403 `PAYMENTS_DISABLED` «Оплата на пилоте отключена — кредиты начисляет команда Wizard». - 2026-10-01 · M2-15 · Лимит токенов платформы: `WIZARD_LLM_MONTHLY_CAP_RUB`, по умолчанию 6000; значение ≤ 0 не пропускает старт. Расход месяца считается как Σ cost_rub строк llm_calls с billable и mode ∈ {live, record} за календарный месяц Europe/Moscow (фиксированно UTC+3: летнего времени нет с 2014). Fixture-вызовы стоят 0, live-eval идёт в CI на своей БД со своим бюджетом. Проверка стоит в `insertRun` для interview_turn, build (create, change, fix) и import_table. Импорт тоже вызывает модель, и это сверх формулировки задачи. Достигнут лимит → 503 `LLM_BUDGET_EXHAUSTED`: «Месячный лимит платформы на работу моделей исчерпан…». 503 выбран как у LLM_UNAVAILABLE: это временный отказ платформы, а не клиента. Проверяется только старт прогона: уже идущие прогоны дорабатывают, и превышение возможно на их cap.

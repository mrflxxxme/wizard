# M0-19 — решения исполнителя

- 2026-09-30 · M0-19 · slice.mjs печатает исходные строки YAML (с комментариями) без отфильтрованных элементов, а не пересериализованный YAML; JSON — поддерево через JSON.stringify, markdown — раздел по заголовку.
- 2026-09-30 · M0-19 · Кроме `milestone`/`x-milestone`, вехой считаются ключи вида `M2`, `methods_M1`, `text_user_M3` (диапазон `M0_M1` — по началу) и комментарий `# Mx` в строке ключа коллекции (`cloud: # M2`); у скалярных колонок комментарии не учитываются (колонки M0-таблиц нужны целиком).
- 2026-09-30 · M0-19 · `--task` по умолчанию режет каждую ссылку по вехе самой задачи (пометка `(slice --milestone Mx)` приоритетнее), `--all` отключает фильтр для ссылок без пометки. Для M0-15 объём 47% полного текста файлов; без фильтра по вехе задачи — 54%, что не проходит критерий ≤ 50%.
- 2026-09-30 · M0-19 · Тесты tools/specs/test/*.test.mjs подключены в корневой vitest.config.ts (biome на tools/ не распространяется, как и на validate.mjs).

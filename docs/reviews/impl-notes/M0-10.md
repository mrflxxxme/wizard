# M0-10 — решения реализации (packages/gates: G0)

- 2026-09-30 · M0-10 · runGates асинхронный (Promise<GateReport>): сборка и теневая схема асинхронны; тип совпадает с GateRunner в platform-api. G1/G2 до M0-11/M2 возвращают отчёт с одной записью status=error (passed=false), а не бросают исключение.
- 2026-09-30 · M0-10 · Проверка интеграций по connector-interface.md §4 (configSchema + validateSpec + обязательные secretRefs, validateIntegrations из @wizard/connectors) входит в G0-SPEC-02: отдельного id в gates.yaml нет.
- 2026-09-30 · M0-10 · G0-TS-01: самодостаточного ui-kit.d.ts пока нет, поэтому @wizard/ui-kit в tsconfig.system подменяется на исходники ui-kit (src/index.ts). Если пакет начнёт поставлять src/ui-kit.d.ts, gates возьмёт его. Вместо временного каталога ревизия лежит в виртуальном корне /__wizard_system__ (ui/**, functions/**, _generated/wizard.d.ts). Компилятор читает с диска только packages/, node_modules/ и lib TypeScript. Диагностики собираются только по файлам системы. Библиотечные SourceFile кешируются между прогонами (форум: ~1,5 с холодный, ~0,4 с тёплый).
- 2026-09-30 · M0-10 · G0-IDX-01: ошибки tsc, попавшие в диапазон `where` у вызовов ctx.db/systemDb.<e>.list/first/count/paginate, переносятся из G0-TS-01 в G0-IDX-01 («where не опирается на индекс»). Лимиты (100/1000/200) проверяются только у числовых литералов, нелитеральные значения ограничивает runtime.
- 2026-09-30 · M0-10 · G0-SEC-01 расширяет forbidden_api (расширять можно). Reflect и Object.getOwnPropertyDescriptor(s) запрещены целиком. Также запрещены importScripts, insertAdjacentHTML, window.frames, теги frame/frameset/object/embed и атрибут formAction. Имена parent/top/opener/name/self/global/open не блокируются, если объявлены в самом файле, иначе ложные срабатывания на `const top`. window.open разрешён только со строковым адресом, который начинается с «/», но не с «//».
- 2026-09-30 · M0-10 · «localStorage/sessionStorage для полей pii≠none» — эвристика: блок, если файл ui/** обращается к хранилищу и упоминает (идентификатор или строка) имя поля с pii≠none из спеки. «Строки SQL как аргументы SDK» — регулярка по SQL-конструкциям в строковых/шаблонных литералах внутри аргументов вызовов с корнем `ctx`.
- 2026-09-30 · M0-10 · G0-IMP-01: разрешены только @wizard/sdk и (в ui/**) @wizard/sdk/jsx-runtime, @wizard/ui-kit; подпути host/testing/codegen запрещены. Проверяются также ImportType (`import("x").T`), import = require и директивы /// <reference> — любые запрещены, потому что через них tsc читает файлы хоста.
- 2026-09-30 · M0-10 · G0-SPEC-05: при rowFilterOps запись (create/update/delete) selfSignup-роли должна покрываться rowFilter. Для сущностей с ПДн rowFilter должен покрывать и read.

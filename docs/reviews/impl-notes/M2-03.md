- 2026-10-01 · M2-03 · Пакет — один на QR-интеграцию: в config нет связи «вход → билеты», поэтому `checkpoint` пакет не фильтрует. expiresAt = выдача + 72 ч (конец события в общем случае неизвестен). В ответ манифеста аддитивно добавлены `full` (полный пакет или дельта) и `validStatuses` (устройству нужно знать, какие `s` пропускать).
- 2026-10-01 · M2-03 · cursor = base64url `{v:1,t}`; дельта перечитывает 60 с до курсора (поздно закоммиченные транзакции); курсор битый, из будущего или старше 72 ч → полный пакет. Удалённые носители в дельту не попадают — уходят с ближайшим полным пакетом.
- 2026-10-01 · M2-03 · Sync: билет со статусом вне validStatuses → `revoked` (в спеке нет отдельного результата); scannedAt из будущего обрезается до времени сервера; clock_skew — по необязательному полю тела `sentAt` (часы устройства при отправке, |sentAt − now| > 10 мин), без него — scannedAt > now + 10 мин. Поле `pending` тела пишется в `_w_qr_devices.pending`. Повтор события, чей ответ потерян до записи в `_w_qr_events`, распознаётся по отметке того же устройства с тем же временем → `accepted`. `_w_qr_events` старше 7 дней чистятся при каждом sync. `cursor` ответа sync — время сервера; клиент для дельт использует курсор манифеста.
- 2026-10-01 · M2-03 · deviceId — uuid в IndexedDB (`wz-qr`/`device`), используется и для онлайн-проверок (≤ 64 символов из-за checkin.device_id форума). Схема IndexedDB (`manifests` keyPath key, поле expiresAt; `queue` keyPath clientEventId) общая с service worker — он удаляет просроченные пакеты при активации и по сообщению `wz-qr-purge`; очередь не трогает.
- 2026-10-01 · M2-03 · QrScanner offline: без сети или при сетевой ошибке онлайн-проверки — проверка по h; локальные отметки хранятся в пакете (`local`) после синхронизации и в очереди до неё; успешная онлайн-проверка тоже помечает h локально. Очередь уходит при событии online и каждые 15 с, пачками ≤ 500 по порядку; удаляются только события с результатом. Серверные duplicate/unknown/revoked событий этой смены переносятся из «Прошли» в «Повторных»/«Отклонено». Без IndexedDB (happy-dom, старые WebView) — хранилище в памяти.
- 2026-10-01 · M2-03 · PWA делает runtime, packages/build не менялся: /manifest.webmanifest (app.name, short_name ≤ 15, ru, standalone, start_url /, theme_color = accent, иконка-монограмма /_wizard/icon.svg «any» и logo.png ≥ 144 px, если есть), /sw.js (версия = система, ревизия, bundleKey, хеш кода воркера; precache «/», ассеты, манифест, иконка, /_wizard/pwa.js), /_wizard/pwa.js (регистрация). Ссылки на манифест и pwa.js runtime вставляет в index.html при отдаче — работает и для артефактов, собранных до M2-03.
- 2026-10-01 · M2-03 · Service worker: навигации, /_wizard/spec и /api/auth/me — network-first с копией из кеша без сети (spec и me прогреваются при активации, иначе первая загрузка не была бы под контролем воркера); /assets/* — cache-first; /api/* и /_wizard/qr/* — всегда сеть. Кеш сессии стирается при logout/dev-logout/отзыве согласия и ответе 401/403. В iframe превью платформы воркер не регистрируется, чтобы пересобранный draft не брался из кеша.

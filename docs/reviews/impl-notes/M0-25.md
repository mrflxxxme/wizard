# M0-25 — решения реализации (packages/ui-kit: компоненты M0)

- 2026-09-30 · M0-25 · Catalog грузит одним запросом pageSize = 24·N (не больше 96 из-за лимита data API ≤ 100); «Показать ещё» исчезает на 96 записях. Распроданные карточки уходят в конец в пределах загруженного набора.
- 2026-09-30 · M0-25 · ItemCard внутри Catalog и Button/Field/Badge внутри компонентов — под-части: только data-testid, без data-wz-component (ui-kit.yaml#rules).
- 2026-09-30 · M0-25 · RecordForm по умолчанию не рендерит поля из readonlyFields, из rowFilter роли (их подставляет сервер) и ref на users; file/json/qr_token не рендерятся никогда.
- 2026-09-30 · M0-25 · Подтверждение действий (confirm, delete) — встроенное в карточку («Подтвердить»/«Отмена»), а не window.confirm.
- 2026-09-30 · M0-25 · DataTable хранит состояние в URL (?sort=&page=&f.<поле>=&q=); при testId ключи получают префикс «<testId>.», чтобы две таблицы на странице не мешали друг другу. На sm строки — карточки через CSS (td::before с data-label).
- 2026-09-30 · M0-25 · DataSource.useCall() принимает имя функции при вызове (mutate(name, args, opts)), чтобы одна карточка могла выполнять несколько kind=fn действий.
- 2026-09-30 · M0-25 · StatusBoard: оптимистичный перенос откатывается при ошибке; во время перетаскивания карточка pointer-events:none, цель определяется по elementsFromPoint. Смещение передаётся через --w-drag-x/--w-drag-y (единственное разрешённое inline-style).
- 2026-09-30 · M0-25 · QrScanner (online): декодер BarcodeDetector, иначе jsQR, загружаемый динамическим import; deviceId — случайный на сессию (без localStorage). Приёмка «fake camera» — Y4M-ролик с QR генерируется в тесте (test/helpers/y4m.ts), повторное считывание того же кода через 3 с даёт duplicate.
- 2026-09-30 · M0-25 · StatsReport: полоса — role=meter на span (нативный <meter> не стилизуется токенами); percent-KPI ожидает долю (0.82 → «82 %»).
- 2026-09-30 · M0-25 · THIRD_PARTY_NOTICES.md в репозитории пока нет: qrcode-generator (MIT, © Kazuhiko Arase) и jsqr (Apache-2.0, © Cosmo Wolfe) попадают в бандлы систем и должны быть туда внесены при его создании.

- 2026-10-01 · M2-05 · delete_system (src/privacy/delete-system.ts) в проходе retention_cron: кандидаты — deleted_at ≤ now − 30 дней и нет записи system_deleted (отметка очистки — сама запись журнала, новой колонки нет). Порядок: перенос остатка _w_deletion_log этой системы → файлы (импорты, архивы экспорта, значения секретов SecretStore.removeSystem, каталог бандлов artifacts/<schema_key>, блобы) → одна транзакция: DROP SCHEMA обоих env (под мигратором), удаление messages, imports, exports, secrets_refs, строк platform.files удалённых блобов и запись deletion_log {env, entity '*', mode system_deleted, rows_affected = строк в users и таблицах сущностей}; система без схем получает одну запись env=draft с 0. Падение между файлами и транзакцией повторяет проход. revisions, runs, gate_reports, llm_calls не трогаются (их нет в workflows.yaml#delete_system).
- 2026-10-01 · M2-05 · Блобы «на которые не ссылается другая система»: ссылки = files_manifest_sha ревизий + файлы манифестов; общий набор считается один раз на проход по ревизиям всех не-кандидатов; пустой манифест не удаляется никогда. Окно гонки (другая система в эту миллисекунду записывает тот же блоб) не закрыто — content-addressed put перезапишет файл при следующей записи.
- 2026-10-01 · M2-05 · Событие владельцу об отзыве согласия: письмо kind=notice (OutboxMailer локально) каждому owner org, когда перенос приносит строки mode=consent_revoked; только счётчики, без данных пользователя. Сигнал — журнал удаления, поэтому при withdrawalDays > 0 письмо приходит в момент обезличивания (≤ 30 дней), а не в момент отзыва; отметку «отзыв без обезличивания» (_w_audit op=consent_revoked_pending) платформа не читает — для неё нужен водяной знак.

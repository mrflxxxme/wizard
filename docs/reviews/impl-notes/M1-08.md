# M1-08 — вкладка «Код» и понятный diff: решения

- 2026-09-30 · M1-08 · S7 до сборки (stage=card, card.kind=change) показывает мини-карточку «Что меняется» (как в M0). Ревизии N+1 тогда ещё нет, поэтому diff по changes появляется после сборки правки: stage=ready и публикуемая ревизия > prodRevision. В чате — карточка «Что изменится» (diff-card), в main — сегменты Prod / Черновик / Изменения. Пустой diff, например после «Отменить», карточку не показывает.
- 2026-09-30 · M1-08 · Публикуемая ревизия берётся как в getSystem.publishBlockers: последняя ревизия, если её G0 не провален, иначе previewRevision. diff запрашивается как GET /revisions/:v/diff?from=<prodRevision>.
- 2026-09-30 · M1-08 · Знак строки (+ / ~ / −) выводится из формулировки text_ru. В api.yaml у change нет поля знака, а формулировки diffSpecs (@wizard/appspec) и строк файлов детерминированы. Тест сверяет знаки на настоящем diffSpecs(forum, изменённый forum). Вердикт миграции: любая destructive=true даёт «удаляет данные» и блокирует «Опубликовать» текстом DESTRUCTIVE_IN_PROD из platform-api. Если в diff есть строки entity/field, вердикт «аддитивная», иначе «не требуется».
- 2026-09-30 · M1-08 · «Цена» в diff-card — creditsUsed завершённого прогона сборки, если он виден в сессии, иначе «появится после сборки». Баланс и оценки кредитов относятся к M1-03.
- 2026-09-30 · M1-08 · «Код» — отдельная страница /s/:id/code (rail + дерево + просмотр) без чата. Так на странице нет textarea, как требует acceptance S-code. Вкладки Превью/Код одинаковы на обеих страницах (MainTabs). Подсветка синтаксиса — свой токенизатор TS/TSX (ключевые слова, строки, комментарии, числа, теги JSX): в architecture.yaml#stack нет подсветчика. Токены выводятся только текстовыми узлами React. «Изменения ревизии» — построчный LCS-diff файла с родительской ревизией (общие префикс и суффикс отрезаются, таблица до 4 млн ячеек, иначе файл показывается целиком с пометкой). Бинарные файлы (octet-stream) не показываются и не скачиваются. Краткое ai_notice (compliance.yaml#platform.rules) — заглушка до текста юриста.
- 2026-09-30 · M1-08 · Playwright-стенд M1 — packages/e2e/stand/m1.ts: platform-api в session-режиме с dev-login, настоящий runtime с DbRegistry, Vite platform-web на портах 4210/4110/5183, своя БД wz_e2e_m1_* (удаляется при остановке, осиротевшие БД без подключений удаляются при старте). Строитель и интервью заскриптованы: создание — forum.json ops + specs/runtime/examples, правка — add_field «Тема трека» в заявки спикеров. LLM-фикстуры правки нет, как и в M1-04. Проект Playwright «m1» в том же playwright.config.ts, webServer — массив (M0-стенд dev.mjs и M1-стенд).

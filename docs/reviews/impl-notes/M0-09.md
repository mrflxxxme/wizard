# M0-09 — решения исполнителя

- 2026-09-30 · M0-09 · Интерфейс DataAccess (apps/runtime/src/data/access.ts) опубликован отдельным коммитом первым; режим транзакции расширен значением "default" (READ COMMITTED) для data API и служебных запросов; query/mutation — READ ONLY REPEATABLE READ / SERIALIZABLE по sdk.md §2.2.
- 2026-09-30 · M0-09 · kysely 0.28 используется только как компилятор SQL (DummyDriver + PostgresQueryCompiler), исполнение — postgres.js (tx.unsafe с параметрами): стороннего диалекта kysely-postgres-js не нужно.
- 2026-09-30 · M0-09 · Каждая транзакция делает set_config('role', <dbRole>, true) (по умолчанию wizard_runtime, опция dbRole): локально соединение идёт под superuser wizard, без переключения роли RLS не действовал бы. Роль wizard_runtime в локальной БД пока не создаётся (M0-15/скрипт БД); тесты создают свою роль на файл.
- 2026-09-30 · M0-09 · wizard.user_attrs содержит поля users кроме id/role, включая phone, email, telegram_id: они нужны RLS для $user.phone/email/telegram_id (ops.yaml#semantic_rules) — расхождение с «без контактов» в runtime.yaml#postgres.context; значения живут только в GUC транзакции и клиенту не отдаются.
- 2026-09-30 · M0-09 · RoleSpec.compliance: consentTextHash = sha256(consentText), policyVersion = первые 16 hex sha256 от [consentText, policyPage, operatorName, operatorContact, operatorAddress, operatorInn]. Без consentText согласие дать нельзя → CONSENT_REQUIRED для не-админов на сущностях с ПДн.
- 2026-09-30 · M0-09 · _consent требуется и при update строки сущности с pii≠none (буквально runtime.yaml#data_api.writes), в ctx.db не проверяется (это делает /api/fn по collectsPii).
- 2026-09-30 · M0-09 · Create/update ролью без read возвращает {item: {id}}: INSERT … RETURNING потребовал бы SELECT-политику RLS; id генерируется в runtime (randomUUID).
- 2026-09-30 · M0-09 · 409 CONFLICT: DETAIL нарушения уникальности под RLS скрыт Postgres'ом, поле берётся из имени ограничения uq_<table>$<col> (ops.yaml#ddl_rules).
- 2026-09-30 · M0-09 · ctx.db.paginate: курсор — смещение (base64url); keyset-пагинация — при необходимости позже.

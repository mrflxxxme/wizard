# Яндекс VibeCraft: конкурентный аудит (30.09.2026)

## Сводка

- **Что это.** Lovable-подобный генератор full-stack веб-приложений от Yandex B2B Tech. Публичная бета с 25.06.2026, статус Preview, SLA нет ([Яндекс](https://yandex.ru/company/news/25-06-2026-04), [docs](https://sourcecraft.dev/portal/docs/ru/vibecraft/concepts/)).
- **Харнесс.** Два агента, «менеджер» и «программист», работают на «ансамбле моделей Яндекса». Агент правит git-копию в SourceCraft Spaces, поднимает приложение через Docker Compose и пушит коммит. На задачу даётся 30 минут ([Habr, Яндекс](https://habr.com/ru/companies/yandex_cloud_and_infra/articles/1084654/), [how-it-works](https://sourcecraft.dev/portal/docs/ru/vibecraft/concepts/how-it-works)).
- **Стек.** Приложения на TypeScript/Node.js + React (по наблюдению обозревателя — Next.js, Tailwind, shadcn). Данные — в serverless YDB, запуск — в Serverless Containers.
- **Деньги.** Считаются в нейрокредитах, 1 нк = 1 ₽ сверх пакета. С 01.10.2026 действует сетка SourceCraft: Free — 500 нк/мес, Start — 1 190 ₽, Go — 2 490 ₽, X5 — 5 490 ₽, X15 — 11 490 ₽. Ресурсы Yandex Cloud оплачиваются отдельно ([pricing](https://sourcecraft.dev/portal/docs/ru/sourcecraft/pricing)).
- **Слабые места.** Время сборки (сайт автосервиса — 52 минуты и 530 нк), галлюцинации данных, вход только через Яндекс ID и только на платном плане со своим доменом, нет коннекторов (платежи и прочее пока в роадмапе). Про миграции и QA документация молчит. Жёсткая привязка к Yandex Cloud.
- **Вывод для Wizard.** Конкурировать «чатом + превью + хостингом» бессмысленно. У Яндекса трафик, бесплатный уровень и бренд. Выиграть можно на том, чего VibeCraft структурно не делает: предметная модель с безопасными миграциями, проверяемые права, готовые коннекторы (amoCRM, ЮKassa, Telegram, SMS), 152-ФЗ «из коробки», вертикальная глубина и предсказуемая цена за результат.

## 2. Технологии и харнесс

- **Модели.** Официально это «ансамбль моделей Яндекса» из Yandex AI Studio ([Habr](https://habr.com/ru/companies/yandex_cloud_and_infra/articles/1084654/), [kod.ru](https://kod.ru/yandex-b2b-tech-vibecraft)). Названия не раскрываются, в документации Code Assistant — только «мощная модель для кода от Яндекса» ([профили](https://sourcecraft.dev/portal/docs/ru/code-assistant/operations/agent/api-configuration-profiles)). Обозреватель пишет, что агент стабильно называл себя Claude, а в ответах API встречался служебный текст с упоминанием Claude [?] ([Habr](https://habr.com/ru/articles/1070724/), [комментарии](https://habr.com/ru/articles/1070724/comments/)). Code Assistant поддерживает BYOM и MCP ([портал](https://sourcecraft.dev/portal/code-assistant/)). Внешние модели доступны на платных планах ([pricing](https://sourcecraft.dev/portal/docs/ru/sourcecraft/pricing)).
- **Харнесс.** По наблюдениям обозревателя, в основе OpenCode (MIT), AGENTS.md и eval-папки под shadcn [?] ([Habr](https://habr.com/ru/articles/1070724/)). SourceCraft CLI, по словам комментаторов, — «подготовленная версия OpenCode» ([Habr](https://habr.com/ru/news/1026498/comments/)). Роли агентов ограничены набором инструментов, а не промптом. Есть детектор зацикливания ([Habr](https://habr.com/ru/companies/yandex_cloud_and_infra/articles/1084654/)).
- **Инфраструктура.** Используются SourceCraft Spaces, Container Registry, Serverless Containers, YDB, Lockbox, API Gateway и Cloud DNS ([how-it-works](https://sourcecraft.dev/portal/docs/ru/vibecraft/concepts/how-it-works)).
- **QA.** Агент «запускает и проверяет». Тестов, e2e-проверок, матрицы прав и гейтов публично нет. SAST, DAST и поиск секретов доступны как отдельный SourceCraft Security за 3 000 ₽ за коммитера в месяц.
- **Надёжность.** Документация сама предупреждает: «гарантированно сохранённым считается только результат, который появился в репозитории». Незавершённая задача может потерять работу, откат при остановке не гарантирован, возможны git-конфликты.
- **Лимиты.** 3 одновременно редактируемых проекта, 10 опубликованных, 30 минут на задачу, плюс квоты сервисов Yandex Cloud ([limits](https://sourcecraft.dev/portal/docs/ru/vibecraft/concepts/limits)).

## 5. Слабые места и боли пользователей

1. **Скорость.** 52 минуты против заявленных 5–10 ([Habr](https://habr.com/ru/articles/1070724/)).
2. **Галлюцинации.** Агент выдумал каталог «Plato Quartet/Line/Terrace» с ценами и выдал его за реальные данные ([комментарии](https://habr.com/ru/articles/1070724/comments/)). Яндекс сам признаёт «услужливые галлюцинации» и зацикливание.
3. **Качество.** В комментариях — «уровень минус второго этажа» и ручная сборка YAML. На сайте не было ни одной картинки.
4. **«Нужен разработчик».** Пресса прямо пишет: «может потребовать доработки» ([CNews](https://www.cnews.ru/news/top/2026-05-26_u_yandeksa_poyavitsya_ii-servis)). Основная среда требует знать git и SSH-ключи ([Habr](https://habr.com/ru/articles/1070724/)).
5. **Привязка.** Вход только через Яндекс ID, хостинг только в Yandex Cloud, база — YDB, диалект которой не Postgres. Перенос на другое облако требует переписывать слой данных [?].
6. **Непрозрачная цена.** Нейрокредиты вызывают сарказм ([Habr CLI](https://habr.com/ru/news/1026498/comments/)), стоимость результата заранее неизвестна.
7. **Интеграций нет.** Нет ЮKassa, Telegram, amoCRM/Битрикс24, SMS, 1С.
8. **ПДн.** Данные лежат в РФ, но генератор не помогает с согласиями, политикой, категориями ПДн и уведомлением РКН. Оператором становится пользователь [?].
9. **Нет гарантий.** Preview, нет SLA, работа может потеряться при таймауте, нет транзакционного отката.
10. **Имидж.** «Клон Lovable», страх фишинга ([комментарии](https://habr.com/ru/companies/yandex_cloud_and_infra/articles/1084654/comments/)).

## 6. Соседи и мировые практики

- **Битрикс24 Вайбкод.** Приложения, чат-боты и AI-агенты **внутри** портала: сразу есть доступ к CRM, задачам и диску, серверы без публичного IP ([FAQ](https://helpdesk.bitrix24.ru/open/28506858/)). Нужны коммерческий тариф и подписка BitrixGPT + Маркетплейс. Оплата вайбами (1 Ꝟ = 1 ₽), при нулевом балансе серверы останавливаются. Публикации в Маркетплейс нет. В отличие от VibeCraft, это не публичные сайты, а внутренняя автоматизация клиента Битрикс24 с партнёрским каналом.
- **amoCRM «Амма».** Ассистент, который настраивает CRM диалогом, анализирует сделки, помогает в переписке и «может создавать элементы интерфейса — например, виджеты на рабочем столе» ([Гензис](https://gnzs.ru/blog/amoconf2026)). Генератора полноценных приложений нет. Для Wizard это окно возможностей.
- **Чего нет у VibeCraft из мировых практик.** Lovable даёт двустороннюю синхронизацию с GitHub, Supabase с RLS, security-scan перед публикацией и визуальные правки. Bolt запускает код в браузере (WebContainers) — превью без облачной песочницы. Replit Agent сам тестирует приложение в браузере и долго работает автономно (по заявлению — часы) [?]. v0 опирается на дизайн-систему shadcn и деплоит в один клик. Base44 даёт встроенные БД, авторизацию по email и готовые интеграции (почта, LLM, платежи). Convex Chef работает поверх типизированной реактивной БД со схемой, которую агент меняет безопасно. Общий паттерн — **детерминированный бэкенд-примитив + автотест + откат**. У VibeCraft есть только git и serverless.

## 8. Вопросы основателю

1. Если через 6 месяцев VibeCraft выпустит шаблон «CRM для ремонта» и коннектор ЮKassa, что у Wizard останется, кроме amoCRM?
2. Сколько бесплатных сборок вы готовы дать, если у Яндекса 4 000 нк на входе? Чем ограничен ваш Free: временем, ролями или продом?
3. Клиент сам сделал прототип в VibeCraft. Чем вы его переманите: импортом, переносом данных, гарантией?
4. «Проверено до публикации» — что именно проверяется? Сможете ли вы показать клиенту отчёт гейтов, который он поймёт?
5. Готовы ли вы отказаться от экспорта кода навсегда? Как ответите интегратору, которому нужен git?

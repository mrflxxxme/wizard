# Исследование перед грилл-8: путь к v3 (08.10.2026)

Сводка четырёх треков, собранных перед гриллом v3: текущее состояние кода, рынок и работа с репозиториями, визуал tier-1 с моделями и BYOK, открытые API с интервью и временем сборки. Метки: **[П]** — первоисточник, **[В]** — вторичный источник, **[О]** — вывод или расчёт. Цены в рублях пересчитаны по курсу ЦБ 83,48 ₽ за $ (03.10.2026). Решения по итогам — в [грилл-8](../reviews/grill-8.md).

## 1. С чего начинаем (main 07236a0, бета v2 закрыта)

- **Система** — это AppSpec (JSON), `ui/**/*.tsx` на `@wizard/ui-kit` и `@wizard/sdk`, `functions/*.ts` и DDL с RLS из `packages/appspec`. Работает она только на нашем runtime (Hono, отдельная схема PG на систему, функции в workerd + gVisor). Выгруженный «репозиторий» без runtime, sdk, ui-kit и appspec не запустится.
- **Модули.** 12 модулей (≈11 100 строк). Модель пишет только данные плана: нишу, цели, модули с параметрами, секции `{type, variant, content}` и дизайн. Фронт собирают шаблонные генераторы. Лендинг строится из 20 типов секций × 3–5 вариантов = 64 раскладки, плюс 10 тем и 21 OFL-шрифт с кириллицей. Этап custom ограничен: ≤ 2 экрана, ≤ 3 функции, без новых сущностей и ролей, без egress.
- **Интервью.** До 4 вопросов с кнопками и «советуем». Итог — ревизия `system_plans`. Этапы сборки получают только утверждённый план, бриф и ответы им не передаются. Загрузки ТЗ из файла нет.
- **Внешние API.** Есть коннекторы yookassa, telegram, email, qr, webhook, egress-прокси и `secret://` (AES-256-GCM). В модульном конвейере интеграций нет. Ввод секрета — только запрос needs_input в v1. Веб-поиска, загрузки страниц и генерации OpenAPI нет.
- **Git.** Интеграций нет. Решения D14, D28, D55 и non_goals закрывают экспорт кода, GZ-13 — «выдача кода клиенту».
- **BYOK** не реализован и не решён. В аудите: «BYOK без маскирования ПДн не открывать».
- **Замер D76.** Сборка ≈ 1 мин и ≈ 4 ₽. От брифа до готовой системы — медиана 2,3 мин.
- **Тарифы D31.** Черновик бесплатен. «Запуск» — 2 990 ₽ разово + 990 ₽/мес, «под ключ» — от 49 000 ₽.

## 3. Репозитории

**Агенты на чужих репозиториях** (Copilot coding agent, Codex cloud, Devin, Jules, Claude Code Actions) [П]:
- Подключение к GitHub — через GitHub App: токен установки живёт 1 час, его можно сузить до одного репозитория и части прав. К GitLab — через OAuth и служебный аккаунт.
- Модель безопасности Copilot:
  - ветка `copilot/*` и только draft PR;
  - агент не одобряет и не мержит;
  - CI на коде агента запускается после «Approve and run workflows»;
  - скрытый текст из issue и комментариев отфильтрован от prompt injection;
  - сессия ≤ 59 мин.
- Codex: setup со своей сетью, на фазе агента сеть выключена или ограничена allowlist доменов.
- Правила репозитория: AGENTS.md — де-факто стандарт (с 09.12.2025 под Linux Foundation), CLAUDE.md, CONTRIBUTING.
- Минимальные права приложения: Contents RW, Pull requests RW, Metadata R, Checks/Statuses R. Право Workflows — только если меняем CI.

**Что удаётся агентам.** По Multi-SWE-bench 2025 решаемость задач: Python 36–46 %, TS 2–11 %, JS 1,4–4,8 % [П]. Новые модели разрыв сократили, но [О] решаемость определяет прежде всего воспроизводимая среда: lockfile, контейнер, быстрые тесты, AGENTS.md. Bitrix/PHP и 1С без тестов, нативные мобильные приложения и монолиты с секретами для сборки агентам плохо поддаются. Sweep свернул бота «issue → PR» из-за низкой надёжности [В].

**Git-хостинг в РФ**
- **GitHub** официально не заблокирован, но с мая 2026 доля неудачных соединений ≈ 16 % [В, OONI]. Страдают `raw.githubusercontent.com` и releases (CDN). 14.07.2026 был час полной недоступности [В]. Санкционные блокировки аккаунтов были в 2022 году. GitHub Enterprise Server в РФ не экспортируется [В].
- **GitLab:** EE под экспортным контролем, CE нет. [О] У российских компаний распространён GitLab CE на своих серверах.
- **GitVerse (СберТех):** публичный API (репозитории, ветки, PR, вебхуки), OAuth 2.0 + PKCE, зеркала npm и PyPI [П].
- **SourceCraft (Яндекс):** API 0.0.1, только токены (≤ 10 репозиториев), OAuth не найден [П].
- **GitFlic:** REST API есть, документация скудная [В].

**Вывод [О].** GitHub нельзя ставить в критический путь сборки. Версии храним у себя в РФ, внешний репозиторий синхронизируем через PR.

## 4. Визуал уровня tier-1

**Как лидеры уходят от плиток.** Никто не генерирует сайт целиком с нуля: структура и стиль разделены.
- Relume: бриф → карта сайта → вайрфреймы из 1000+ неоформленных компонентов → стайлгайд [В].
- Webflow AI: сайт + дизайн-система (переменные, пресеты движения) [П].
- Framer: Wireframer + агент внутри токенов [В].
- v0 Design Systems 2.0 (06.2026): дизайн-система как «скилл», один промпт на пяти системах дал резко разные результаты [В].
- Google Stitch (03.2026): от целей и референсов к нескольким направлениям, правила в DESIGN.md [В].
- **[О]** Плитки дают одна тема на всех и один вариант блока, а не сами модули.

**Почему всё похоже.** Без указаний модель уходит в медиану: Inter, фиолетовый градиент, почти без движения [П, Anthropic 12.11.2025]. Запрет «не повторяйся» не помогает, потому что модель не видит своих прошлых сборок [В]. Разнообразие должна обеспечивать система: выбор направления по seed, память прошлых сборок ниши и метрика сходства скриншотов.

**Визуальная петля работает.** VLM-критик по скриншоту дал +17,8 % за 3 цикла на запросах WebDev Arena [П, arXiv 2604.05839]. ArtifactsBench: открытый судья Qwen2.5-VL-72B совпадает с рейтингом WebDev Arena на 94,4 % [П, arXiv 2507.04952].

**Лицензии** (можно ли раздавать код в сайты многих клиентов):

| Библиотека | Лицензия | Для Wizard |
|---|---|---|
| shadcn/ui, Radix, Motion, HyperUI, Magic UI (бесплатная) | MIT | да, с уведомлениями |
| GSAP Standard (Webflow) | бесплатная проприетарная | не по правилам зависимостей AGENTS.md (не MIT/Apache/BSD/ISC) |
| Tailwind Plus | коммерческая | нет: прямо запрещены конструкторы сайтов [П] |
| Aceternity UI, Magic UI Pro, React Bits Pro | свои/коммерческие | нет [П] |
| React Bits (бесплатная), coss ui | MIT + Commons Clause? / AGPLv3? | не берём до проверки LICENSE |

## 6. BYOK

**Практика**
- OpenRouter берёт 5 % сверх бесплатного объёма [П].
- Cursor пускает свой ключ только в обычный чат, Agent требует их модели [В].
- JetBrains — с 12.2025 [П]. Kilo и Cline — без наценки, зарабатывают на командах [В].
- Платформа всё равно берёт деньги за оркестрацию, песочницу и хостинг. Скидка равна доле стоимости модели.

**Риски**
- Утечка ключа через логи и тексты ошибок.
- Условия провайдеров: OpenAI блокирует доступ из неподдерживаемых стран, РФ не входит в список стран Anthropic [П].
- Лимиты младших тарифов обрывают сборку, а виноватой считают платформу.
- Слабая модель даёт сайты хуже нынешних.

**Право РФ** [В + О, нужен юрист]
- Ключ OpenAI, Anthropic, Google или xAI всё равно означает, что эти API вызывает наш код. Это прямо противоречит D18.
- По чату и аккаунту оператор ПДн — Wizard. Уведомление РКН о трансграничной передаче подаётся до неё, получатель должен быть в нём указан. Произвольный endpoint пользователя указать нельзя.
- Изменения закона: с 01.07.2025 первичный сбор ПДн — только в базы в РФ; с 01.09.2025 согласие — отдельным документом (156-ФЗ); 265-ФЗ от 26.07.2026 касается адекватности стран.

**Хранение ключа.** Конвертное шифрование (OpenBao Transit), расшифровка только в воркере шлюза на время вызова, в интерфейсе последние 4 символа, отзыв, проверочный вызов.

## 7. Поиск, документация, интеграции, секреты

**Поиск.** Яндекс Search API — единственный вариант без проблем с 152-ФЗ и оплатой.
- Цены [П]: 488 ₽ за 1000 синхронных запросов днём, 366 ₽ ночью, 30,5 ₽ отложенных, 5 080 ₽ за 1000 генеративных ответов.
- В AI Studio есть инструмент `web_search` с фильтром доменов (07.2026) [В].
- SearXNG с IP дата-центра упирается в капчи. Brave, Exa, Tavily и SerpAPI не принимают карты РФ, а запросы из чата могут содержать ПДн [В].

**Извлечение страниц.** Crawl4AI (Apache-2.0) + Trafilatura (Apache-2.0 с 1.8.0) отдельным сервисом. Firecrawl — AGPL, антибот-защита только в облаке.

**Документация российских API**
- Официальный OpenAPI есть у ЮKassa [П].
- JSON Schema — у VK (MIT) [В].
- OData `$metadata` — у 1С [В].
- MCP-сервер документации — у Bitrix24, MCP-сервер — у МойСклад [В].
- Неофициальная спека Telegram Bot API (MIT, обновляется ежедневно) [В].
- У СДЭК v2, Т-Банк эквайринга, amoCRM и YCLIENTS официального OpenAPI не найдено.
- llms.txt публикуют 8,7 % топ-1000 сайтов [В].

**Харнесс интеграции**
- Инструменты: openapi-typescript + openapi-fetch (только типы, рантайм ≈ 6 кБ), Prism (мок, Apache-2.0), Schemathesis (контрактные тесты).
- Артефакт — «контракт»: подмножество OpenAPI 3.1 (только используемые операции), сопоставление полей, разрешённые хосты, `secret://`.

**Ключ в чате**
- Lovable: «никогда не вставляйте ключи в чат», агент показывает поле «Add secret» [П].
- n8n: карточка учётных данных в чате, «секреты никогда не отправляются в ИИ» [П].
- MCP 2025-11-25: ключи — только в URL-mode, мимо модели, с показом домена и согласием [П].
- Образец шифрования — секреты GitHub: значение шифруется sealed box публичным ключом в браузере [П].
- [О] Схема для Wizard: инструмент `request_secret` → нативный виджет в чате с доменом получателя → шифрование в браузере → модель видит только `secret://name` → подстановка ключа на egress-прокси, только для хостов из allowlist → проверочный запрос, ротация, отзыв. Объём ≈ 1–2 недели. Без ключа сборка идёт на моке.

## 8. Интервью и бриф-артефакт

- **Spec Kit `/clarify`:** не больше 5 вопросов, строго по одному, у каждого «Recommended: … — причина», «yes» принимает рекомендацию. Ответы записываются в спеку разделом «Q → A» [П].
- **Kiro:** requirements (EARS: «КОГДА … СИСТЕМА ДОЛЖНА»), design с диаграммами, tasks [П].
- **Lovable Plan mode:** план в `.lovable/plan.md`, после одобрения — датированный файл, правка и версии [П].
- **Cursor 2.2:** Mermaid в плане, пользователи жалуются на рендер и синтаксические ошибки [П].
- **Сколько вопросов терпят** (косвенно): у Typeform формы длиннее 6 вопросов заканчивают < 50 %; половина пользователей готова к 6–10 вопросам; 3–5 вариантов ответа работают лучше двух [В].
- **[О] Вывод:** один вопрос за раз, 3–5 кнопок, «Рекомендую», «Решите за меня». Блокирующих вопросов ≤ 8, остальное — явные допущения или вопросы во время сборки. Бриф — структурированный и версионируемый. Схемы по нему рисует код, а не модель.

## 9. Время сборки

- Replit Agent 3 работает до 200 мин, Cursor long-running agents — часами, после плана и одобрения [П].
- Anthropic (11.2025): агент-инициализатор + JSON-список фич, одна фича за раз, сквозные проверки в браузере «драматически» повышают качество [П].
- Ожидание дольше 10 с требует индикатора с процентами [П, NN/g].
- **[О]** 30 мин приемлемы, если превью есть через 3–5 мин, виден чек-лист фич и приходит уведомление о готовности. Расход растёт почти линейно с длительностью, поэтому нужны жёсткий бюджет и правило остановки.

## 1. Зачем v3

Бета v2 доказала, что модульный конвейер надёжен: строгий порог 10 из 10, сборка ≈ 4 ₽ и ≈ 1 мин. Но для первых клиентов этого мало: основатель зовёт их, только когда результат по-настоящему выдающийся.

| Чего не хватает после v2 | Причина в устройстве v2 | Ответ v3 |
|---|---|---|
| Сайты похожи на набор плиток | Фронт собирают шаблонные генераторы модулей: 64 раскладки, 10 тем, один вариант блока на сайт | Модули — только бэк-рецепты. Публичный фронт пишет агент кодом на дизайн-системе клиента и библиотеке паттернов (8–12 вариантов на тип); есть фирменные секции, критик по скриншотам и гейт шаблонности |
| Мало учтено видение клиента | До 4 вопросов, этапам сборки виден только план | Грилл-интервью до ясности, бриф как постоянный артефакт, три направления дизайна с референсами |
| Нет работы с кодом и репозиториями | Код скрыт (D55), системы живут только внутри платформы | Внутренний git, синхронизация с GitHub и GitLab через PR, доработка совместимых репозиториев |
| Нет интеграций с внешними API | Модульный конвейер не использует egress и секреты, у агентов нет поиска | Поиск и чтение страниц, харнесс интеграций с контрактом и моком, окно ключа в чате, паспорта API |
| Нет магазинов и многостраничных сайтов | Таких модулей нет | Модули магазина (оплата, доставка, склад, 54-ФЗ), контент и блог |
| Свои ключи моделей не подключить | BYOK не решён | BYOK к любым провайдерам: согласие, маскирование ПДн, шлюз пользователя |

## 2. Как устроена сборка v3

```
Запрос текстом или файл ТЗ (docx/pdf/md/txt)
  │
  ▼
Грилл-интервью ──► по одному вопросу: рекомендация + 3–5 кнопок + «Решите за меня»
  │                 факты о нише — веб-поиск; «Карта возможностей» по каждому требованию
  │                 стоп: нет блокирующих неясностей (обычно 5–10, потолок 15)
  ▼
Бриф системы v1 ──► тезисы + 3 схемы (путь клиента, данные и роли, интеграции; рисует код)
  │                  версии с подсветкой разницы, журнал «вопрос → ответ», допущения
  ▼
Три направления дизайна ──► 3 настоящих первых экрана с текстами клиента (≈ 20–40 ₽, 1–2 мин)
  │                          логотип и референсы → принципы; выбор или правка словами
  ▼
«Собрать» (одна точка согласования, D7)
  │
  ▼
Харнесс сборки v3 (обычно 10–20 мин, потолок 30 мин и 500 ₽)
  ├─ бэк: модули-рецепты + операции расширения спеки (под гейтами RLS, ПДн, миграций)
  ├─ дизайн-система клиента (токены, шрифты D64, сетка, ритм, движение)
  ├─ превью ≤ 5 мин: каркас всех страниц в выбранном стиле
  ├─ сценарии брифа по одному: код страниц на паттернах + фирменные секции → проверка в браузере
  ├─ интеграции: контракт → клиент → мок → тесты → проверка ключом (окно ключа в чате)
  ├─ критик по скриншотам 390/768/1440 (2–3 цикла) + гейт шаблонности
  └─ техревью: детерминированная часть + ревьюер на модели другого семейства (≤ 2 раунда)
  │
  ▼
Гейты G0–G2 + сценарии брифа в браузере → живое превью → уведомление на почту или в Telegram
  │
  ▼
Правки 1–5 мин · внутренний git (РФ) ⇄ PR в GitHub/GitLab · превью PR · публикация после мержа
```

**Принцип «алгоритмы вперёд моделей».** Всё, что можно посчитать, считает харнесс:
- палитры OKLCH, шкалы шрифтов и сетки;
- выбор архетипа по seed с памятью ниши;
- скоринг паттернов;
- схемы брифа;
- подбор фото из библиотеки (B2-43);
- автоисправления линтером и кодмодами;
- метрика шаблонности.

Модели решают то, что посчитать нельзя: вопросы интервью, тексты, композицию страниц, фирменные секции, оценку критика и ревью.

**Маршрут моделей** (≈ 180–300 ₽ на сборку; таблица цен — в исследовании, §5):
- арт-директор и фирменные секции — GLM-5.x (T1 без ПДн; T0 — GLM-5.1/5.2 или Kimi K2.6);
- массовый код страниц и тексты — дешёвые сильные модели (MiMo-V2.5-Pro, DeepSeek V4 Flash), каждая проходит пробу на русском перед включением;
- критик — Qwen3-VL или GLM-V;
- ревьюер техревью — модель другого семейства, чем у сборщика;
- маршрутизация и проверки — gpt-oss-120b.

Шлюз готов подключить свой vLLM одной настройкой. Список разрешённых моделей шлюза закрывает западные API на ключах платформы (D18).

## 4. Харнесс разработки v3: сначала бесплатное, платное — адресно

Наш харнесс должен быть образцом для клиентского и ещё эффективнее его (решение основателя № 18). Каждая проверка поднимается на следующую ступень, только когда предыдущая зелёная:

| Ступень | Что | Цена | Когда |
|---|---|---|---|
| 0 | Типы, линтер, юнит-тесты, детерминированные генераторы; харнесс на записанных ответах моделей (`WIZARD_LLM_MODE=fixture`) | 0 ₽ | Каждый PR |
| 1 | Браузерные тесты в CI (GitHub-раннеры бесплатны для публичного репозитория); скриншоты, доступность, Lighthouse; метрика шаблонности по DOM и pHash | 0 ₽ | Каждый PR, затрагивающий фронт и сборку |
| 2 | Адресная проба одного этапа на 1–3 брифах самой дешёвой подходящей моделью; ответ записывается (`record`), повтор дальше бесплатен | ≤ 30 ₽ | Новый промпт или этап, после зелёного CI |
| 3 | Одна сквозная сборка на целевом маршруте | ≤ 500 ₽ | Этапы на ступени 2 зелёные |
| 4 | Чекпоинты основателя и финальный замер | по плану | Конец волны A; финал |

**Правила:**
- Платный прогон — только после зелёного CI (как раньше).
- Перед платным прогоном — запись в журнале трат: цель, гипотеза, ожидаемые ₽, потолок. На потолке прогон автоматически останавливается.
- Упал бриф — разбираем его адресно (этап, вход, записанный ответ). Полный прогон заново не запускаем.
- Каждый отчёт и каждое сообщение основателю содержат строку «потрачено X ₽ из плана Y ₽ волны».
- Дороже 1 000 ₽ за раз или выход за план волны — только с «да» основателя (развилка через /grill-me).

**Лимиты платформы на время v3:**
- сутки — 3 000 ₽, месяц — 15 000 ₽ (вместо 700 и 6 000 ₽); оповещения на 50 % и 80 %;
- сборки основателя — отдельный лимит 2 500 ₽ в месяц.

Расходы на инфраструктуру (Yandex Search API, сервис чтения страниц) — в пределах существующего сервера и копеек на запрос: около 15 ₽ на сборку входят в цену сборки.

## 6. Критерий выхода v3 (допуск первых клиентов)

1. **Функционально.** 12 брифов (по 3 на класс: сайт бизнеса, услуги с записью, CRM или админ-система, магазин) собраны. Сценарии брифа проходят, техревью без блокеров.
2. **Слепое сравнение.** Те же 12 брифов у конкурента (VibeCraft, Tilda AI, Lovable — кто доступен). Основатель и 3–5 независимых оценщиков сравнивают пары, не зная, чей сайт чей. Wizard выигрывает ≥ 70 % пар.
3. **Разнообразие.** Сходство скриншотов внутри ниши ниже порога; ни один оценщик не называет два сайта «одним шаблоном».
4. **Время и деньги.** Медиана ≤ 20 мин, максимум 30 мин. Средняя сборка ≤ 300 ₽, ни одна не дороже 500 ₽.
5. **Эргономика.** Основатель и 3–4 нетехнических знакомых сами собирают свои системы без подсказок; минимум трое из четырёх говорят «заплатил бы».

Затем «да» основателя и первые клиенты. Граница бесплатного тарифа и цены решаются в этот момент по данным v3.

## 7. Риски и ответы

| Риск | Ответ |
|---|---|
| Свободный код фронта ломает надёжность v2 | Бэк остаётся модульным; фронт проходит линтер, сценарии в браузере, критик и техревью; если фирменная секция не прошла — ставится паттерн |
| Дешёвые модели слабы на русском | Каждая модель проходит пробу (ступень 2) до включения в маршрут; запасной путь — GLM |
| Длинная сборка дорожает | Потолки 30 мин и 500 ₽ с автостопом, кэш промптов, алгоритмы вперёд моделей |
| GitHub из РФ нестабилен | Источник истины — внутренний git, синхронизация в очереди с повторами; сборка от GitHub не зависит |
| BYOK: юридические риски | Маскирование ПДн, своих обходов геоблокировок нет, согласие пользователя, юрист до публичного включения |
| Лицензии паттернов | Только MIT и Apache с записью в THIRD_PARTY_NOTICES; Tailwind Plus, Aceternity, Magic UI Pro и GSAP не берём |
| Разнообразие ради разнообразия вредит конверсии | Архетипы подбираются под нишу и цели; критик оценивает и читаемость, и путь к цели; слепое сравнение решает |

# План: бета v4 Born to Build (Wizard)

Дата: 11.10.2026. Решения: [грилл-9](../reviews/grill-9.md), `specs/product.yaml#decisions.D79_v4`. Задачи: веха **V4** в `specs/milestones.yaml`, `V4-01…V4-14` в `specs/backlog.yaml`.

## 1. Цель

Первый боевой прототип с вау-эффектом. Через минуту после первого сообщения владелец видит три красивых первых экрана про свой бизнес. Через 15 минут у него живая система на весь экран: заявки и запись работают, сайт не похож на шаблон. Переход в альфу — «да» основателя по его сборкам. Волна идёт непрерывно, агенты работают круглосуточно, ориентир — несколько дней.

## 2. Путь владельца

```
Первое сообщение (текст или файл ТЗ)
  ├─ ≤ 90 с: три первых экрана на весь холст (код модели, фото из библиотеки, тексты про бизнес)
  └─ параллельно в свёрнутом чате: 3–5 блокирующих вопросов
  ▼
Выбор направления = «Собрать» (точка согласования D7)
  ▼
≤ 3 мин: живой каркас всех страниц в выбранном стиле → ≤ 15 мин: система
  ├─ страницы — свободный TSX на токенах; формы, запись, корзина, вход — компоненты SDK
  ├─ первый экран — 2 кандидата разных семейств, судья другого семейства
  ├─ критик по снимкам 390/1440 правит код (2 цикла); решают детерминированные проверки
  ├─ бэк — модули-рецепты v3 + операции под гейтами (без изменений)
  └─ неблокирующие вопросы — карточками с ответом по умолчанию
  ▼
Правки: мгновенные (текст, фото, ползунки) · «Укажи и измени» ≤ 60 с · чат
```

## 3. Модели (ключи платформы; западные — только BYOK, D18)

| Роль | Основная | Запасная |
|---|---|---|

| Арт-директор, три направления | Kimi K3 (Moonshot) | GLM-5.3 |

| Техревью | MiMo V2.6 Pro | gpt-oss-120b |
| ИИ в runtime (данные клиентов) | только РФ, как в v3 | — |

**Правила:**
- Этапы сборки идут без маскирования ПДн. Сигнальный фильтр ловит паспорт, СНИЛС и номер карты.
- Runtime — только РФ.
- Ollama Cloud — только для замеров основателя.
- Каждая новая модель проходит пробу на русском (2–3 входа этапа) до включения в маршрут.

## 5. Тесты (D79 (10))

1. **Записи настоящих ответов моделей.** Ключ записи — версия промпта + модель + схема инструментов. CI проигрывает записи; если записи нет — громкий провал вместо тихого запасного пути.
2. **Живая проба изменённого этапа.** Перед PR агент прогоняет живой моделью только изменённый этап на 2–3 сохранённых входах (5–15 ₽). Ответы пробы становятся записями.
3. **Сборка основателя = приёмка.** Отчёт сохраняется сам: снимки, гейты, критик, сценарии, HTTP-ответы, ₽ и минуты. Провал становится задачей агента.

Замеров по расписанию, канареек и предрегистрации трат нет. Лимиты суток и месяца D77 (18б) остаются предохранителем.

## 6. Критерий выхода

«Да» основателя по его сборкам (D79 (12)). Ориентиры показывает отчёт, переход они не блокируют:
- три экрана — до 90 с;
- система — до 15 мин;
- сборка — до 300 ₽.

# Wizard

Сервис для небольших компаний заказных услуг (старт — ремонт и отделка): компания описывает свой процесс в чате, отвечает на уточняющие вопросы кнопками, и агенты собирают операционную систему заказа (смета, этапы, бригады, фотоотчёты, оплаты, связь с amoCRM). Система проходит проверки качества и публикуется в российском облаке.

# Wizard

AI-платформа для российского малого бизнеса: пользователь описывает задачу в чате, отвечает на уточняющие вопросы кнопками, и команда агентов собирает работающую систему (данные, права, интерфейс, интеграции). Система появляется в живом превью под чатом и публикуется в российском облаке.
